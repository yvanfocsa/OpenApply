# Rapports automatiques OpenApply

Ce dossier reçoit un rapport Markdown et un rapport JSON lorsqu’une étape échoue ou dépasse le délai d’observation.

Les rapports contiennent l’étape, le moteur, le modèle, le diagnostic, le checkpoint disponible et une sortie technique nettoyée. Les offres, les clés API, les jetons d’accès et les adresses e-mail ne sont pas copiés dans les rapports.

Les fichiers de rapport sont ignorés par Git. Seul ce fichier explicatif est versionné.
